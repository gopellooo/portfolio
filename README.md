# Portfolio

Портфолио продуктового дизайнера Сергея Соколова.

- [Главная страница](https://gopellooo.github.io/portfolio/)
- [Кейс ЕКОМ+](https://gopellooo.github.io/portfolio/ekom/)

В репозитории находится готовый статический сайт. GitHub Pages публикует основную ветку из корневой папки.

Правки главной страницы вносятся в исходный React/Vite-проект, затем выполняется сборка и её результат загружается сюда. Кейс ЕКОМ+ хранится в папке `ekom`; при повторной сборке исходного проекта его копия находится в `public/ekom`.

Для публикации сохраняйте файл `.nojekyll` и расположение папок. Серверная часть и база данных не требуются.
